# ShareBill24

> *"Split the bill, not the vibe"*

Mini web app giúp nhóm bạn chia tiền bill một cách thông minh, nhanh chóng và vui vẻ.

## Tech Stack

### Frontend
- Next.js 16.2 (App Router)
- TypeScript 5.x
- Tailwind CSS 4.x
- shadcn/ui
- Zustand + React Query
- Framer Motion
- Recharts

### Backend (coming soon)
- NestJS 11.x
- Prisma 5.x
- PostgreSQL 16
- ZhipuAI GLM-5

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Features

- ✅ Vibe theming (Food, Drinks, Travel, Shopping, Party, Cafe, Sports)
- ✅ Debt simplification algorithm
- ✅ Quick copy message for Zalo/Messenger
- ✅ Timeline visualization
- ✅ PWA support (coming soon)
